## 三、现在能说的实测数字（两套评测集各 20 张，可重跑）

- **全字段 100%、误放行 0**（正常字体集与退化字体集都是）；
- 单据编号：严格字面 **100%**（正常字体）；归一 **100%**（退化字体，严格 5%——真值不在图上，如实暴露）；
- 成本 ~1800 提示 + 301 生成 token/张（OCR 已不进模型），抽取 p50 **665ms**；
- 口径声明：单集 20 张、±5 个点；多次运行取中位数为最终口径。

## 四、旧数字的正确讲法（面试防坑）

旧版「OCR 编号 100% vs 直读 30%」**不要再引用**。被问到时：
「那组对比是评测集假象——我做对照实验：同一张图只改真值重渲染，OCR 输出一字不变，
证实 OCR 输出与真值零相关、差距源于评测集编号字体 O/0 同形。修复评测集并迁移直读
架构后，两场景全字段 100%、误放行 0。详见《eval/报告-live-20261026.md》补记 3/4 与终版章节。」
